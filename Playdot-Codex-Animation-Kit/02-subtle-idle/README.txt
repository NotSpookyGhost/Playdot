PLAYDOT — SUBTLE LOOP

A quiet companion to the playful entrance animation. The settled wordmark stays in place, with two short blinks, a small sideways glance, and a very gentle bob of the smiling o. No repeated entrance, fading or flashing.

FILES
Playdot-subtle-loop.svg: self-contained animated vector asset with a transparent background.
Playdot-subtle-loop.html: responsive navy-background preview with Pause / Resume and reduced-motion support. Open in a modern browser.

TIMING
Eight-second seamless loop. Motion rests at the boundary: the first and last poses are identical. The small o movement is only 9 SVG units, around 7 display pixels in a 1920-pixel-wide preview. The letters never change position.

ACCESSIBILITY
Both files honor prefers-reduced-motion: reduce and show the finished logo without animation. The HTML provides a keyboard-accessible Pause / Resume control.

WEBSITE USE
No external assets or dependencies. Inline the SVG to integrate it into a component. Retain the embedded CSS and viewBox. The SVG is transparent; the HTML preview uses navy #111a30. If using multiple inline copies, rename each copy's pd- identifiers and matching references to keep them unique.

To use the MP4 as a loop on a website, set the video element to muted, autoplay, loop and playsinline, and provide a static alternative for reduced-motion users. The GIF loops automatically.

ARTWORK
Uses the same cleaned, traced colourful Playdot vectors as the approved entrance animation. Facial features are vector reconstructions. This is an animation-ready adaptation, not an original vector master. The earlier entrance files are preserved unchanged.
